# Muscle Atlas

A responsive, browser-only reference for major superficial muscle groups. Select an area on the front or back anatomy map, search by muscle name, or filter by body region to see example stretches and common sources of discomfort.

## Run it

Open `index.html` in a modern browser. The project uses plain HTML, CSS, and JavaScript; it has no build step, package install, external font, API, or server requirement.

## Scope and safety

The clickable diagrams are stylized guides to 20 major muscle groups, not a complete map of all anatomical muscles and not a diagnostic tool. Stretch gently and stop if pain increases. Seek urgent care for chest pain, sudden weakness, major swelling, or pain after serious injury.
