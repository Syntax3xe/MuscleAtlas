# Muscle Atlas

A responsive, browser-only reference for major superficial muscle groups. Select an area on the front or back anatomy map, search by muscle name, or filter by body region to see example stretches with step-by-step cues, dosage suggestions, source guides, and common sources of discomfort.

## Run it

Open `index.html` in a modern browser. The project uses plain HTML, CSS, and JavaScript; it has no build step, package install, external font, API, or server requirement.

## Scope and safety

The clickable diagrams are stylized guides to 20 major muscle groups, not a complete map of all anatomical muscles and not a diagnostic tool. Stretch suggestions are general examples informed by NHS, AAOS, and Harvard Health guidance; they are not a personalized treatment plan. Warm up first, move gently, and stop if pain increases. Follow advice from your clinician. Seek urgent care for chest pain, sudden weakness, major swelling, or pain after serious injury.
